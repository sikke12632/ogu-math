# Firestore 켜기 — 선생님이 직접 하셔야 하는 5분

앱을 Realtime Database 에서 **Firestore 로 옮겼다.** 학교 필터(웹키퍼)가
`*.firebasedatabase.app` 을 막는 일이 있었기 때문이다. Firestore 는 주소가
`firestore.googleapis.com` 이라 구글 주소에 들어가고, 학교가 그걸 막으면
구글 클래스룸도 같이 죽으므로 사실상 막지 못한다.

**콘솔에서 데이터베이스를 만드는 것은 사람만 할 수 있다.** 아래 순서대로 하면 된다.
다 하기 전에는 앱이 안 돈다.

---

## 1. Firestore 데이터베이스 만들기

1. https://console.firebase.google.com 접속 → **math-game-e3402** 프로젝트 선택
2. 왼쪽 메뉴 **빌드 → Firestore Database**
3. **데이터베이스 만들기** 클릭
4. **위치**를 고르라고 나온다 → **`asia-northeast3 (Seoul)`** 을 고른다

   > **위치는 나중에 못 바꾼다.** 서울로 골라야 한다.
   > 지금 쓰던 Realtime Database 는 싱가포르라, 서울로 바꾸면 오히려 조금 빨라진다.

5. 모드를 물으면 **프로덕션 모드**로 시작한다 (다음 단계에서 규칙을 넣을 것이다)
6. **사용 설정** 클릭. 1~2분 걸린다

## 2. 규칙 붙여넣기

1. Firestore Database 화면에서 위쪽 **규칙** 탭
2. 안에 있는 내용을 **전부 지우고**, 프로젝트 폴더의 **`firestore.rules`** 파일 내용을 통째로 붙여넣는다
3. **게시** 클릭

붙여넣을 내용은 이렇게 시작한다.

```
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
```

## 3. 확인

브라우저에서 이 주소를 연다.

```
https://sikke12632.github.io/ogu-math/#/check
```

**"실제로 읽어 보기" 와 "실제로 써 보기" 가 초록불이면 끝난 것이다.**

빨간불이면 이렇게 읽는다.

| 증상 | 뜻 |
|---|---|
| 읽기·쓰기 둘 다 ✗, "permission" 이라는 말이 보임 | 규칙을 안 붙여넣었거나 게시를 안 누름 |
| 읽기·쓰기 둘 다 ✗, "not found" 또는 "does not exist" | 데이터베이스를 아직 안 만듦 |
| 데이터 서버(`firestore.googleapis.com`) 가 ✗ | 이 기기에서 그 주소가 막힘. 이건 다른 문제 |

## 예전 것은 어떻게 되나

**Realtime Database 는 이제 앱이 쓰지 않는다.** 그냥 둬도 되고 지워도 된다.

안에 있던 것은 시험 삼아 돌려 본 기록뿐이라 **옮기지 않았다.**
`/review` 는 이제부터 쌓이는 것만 보여 준다.

> 되돌릴 일이 생길 수 있으니 **당장 지우지는 말고 한두 주 두는 편이 낫다.**

---

## 되돌리려면

Firestore 로 옮기고 나서 문제가 생기면 예전 상태로 돌아갈 수 있다.

```bash
git checkout 리얼타임DB-마지막-작동본
```

이 표시는 옮기기 직전 상태를 가리킨다. Realtime Database 를 지우지 않았다면
그대로 다시 돌아간다.

---

## 사용량 걱정은 안 해도 되나

Firestore 는 읽고 쓴 횟수로 값을 매긴다. 무료 한도는 하루 **읽기 5만 · 쓰기 2만** 이다.

앱은 이 한도를 넘지 않도록 만들어져 있다.

- **"나 여기 있어요" 신호를 대전 중에만 촘촘히 보낸다.** 그 밖에는 20초에 한 번이다.
  이걸 안 하면 한 시간 수업 한 번에 하루치를 다 쓴다
- 문항처럼 크고 안 바뀌는 것은 따로 떼어 두어 매번 다시 받지 않는다

25명이 한 시간 수업을 해도 쓰기 오천 번 안쪽이다. 하루 두 반씩 해도 한도 안이다.
