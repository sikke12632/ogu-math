# 인수인계 — 2단원 상 난이도 숫자 조정

## 할 일

2단원(5-2 분수의 곱셈) **상 난이도 문항의 숫자가 너무 쉽다.**
유형은 대체로 괜찮다. 숫자가 문제다 — `1/2 × 12`, `16 m 의 1/4`, 분모 2·3·4 같은 것들이
암산으로 끝나서 상 문항이 상 답지 않다. **고난도는 고난도답게 나와야 한다.**

선생님 기준은 숫자를 보고 판단하는 것이다. 유형 설명이나 주석 말고 **실제로 뽑힌 문항**으로 확인할 것.

## 2단원 코드

`src/units/5-2-2/`

| 파일 | 내용 |
|---|---|
| `frac.ts` | 분수 계산·표기(`show`, `showMixed`), 오답 생성(`distractors`), 조사(`josa`, `josaAfter`) |
| `calc.ts` | T1~T6 계산 (하·중) |
| `apply.ts` | T7 중첩 비율, T8 단위, T11 도형 (중·상) |
| `judge.ts` | T9 잘못 계산한 것, T10 수 카드 (상) |
| `hard.ts` | T12 거꾸로 구하기, T13 남은 것, T14 자연수 만들기, T15 크기 판단 (상) |
| `hard2.ts` | T16 역산+중첩, T17 □ 자연수 개수, T18 튀어오르는 공, T19 속력 (상) |
| `index.ts` | 유형 등록, 세트 조립 |

숫자는 거의 다 각 생성 함수 안의 `rng.pick([...])` / `rng.int(a, b)` 와 그 아래 가드(`return null`)에서 정해진다.

## 확인 방법

```bash
npm run dump -- 5-2-2 3 2    # 상 난이도, 유형별 2개 → out/dump-5-2-2-난이도3.html
npm run check:2              # 2단원 검수기 (정답 재계산·표기·생성 성공률)
npx tsc --noEmit
```

`check:2` 는 가드가 너무 빡빡하면 "600번 중 N번만 만들어졌습니다" 로 실패한다. 숫자를 어렵게 조이면 이게 먼저 걸린다.

## 지켜야 할 것

- **시중 문항 복제 금지.** 수치만 바꾸는 것도 복제다. 유형(얼개)만 가져온다
- **분수 답은 선택형.** 크롬북에서 `4와 2/7` 을 칠 수 없다. 단답형은 자연수 답만
- 분수 표기는 `[3/4]`, `[1_2/3]`. 가분수를 문제에 내놓지 않는다(검수기가 막는다). 분모 48 초과 금지
- 오답 보기는 아이들이 실제로 하는 실수에서 뽑는다 (분모에도 곱함, 자연수만 곱함 등)
- 조사는 숫자를 읽는 소리로 정한다 — `josa`/`josaAfter` 를 쓸 것 ("3분의 2**를**")
- 답이 하나여야 한다. 모양이나 크기만 보고 찍히면 안 된다
- 5학년 2학기 범위: 분수의 곱셈까지. **분수의 나눗셈은 6학년** (T12 가 그래서 선택형이다)
- 배포는 선생님이 말할 때만. 수업 중에는 절대 푸시하지 않는다
